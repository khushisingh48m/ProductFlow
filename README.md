# ProductFlow

ProductFlow is a simple full-stack web application for managing products.

## What it does

- User can register and login
- Add new products
- View products
- Edit product details
- Delete products
- Set product status as Active or Inactive
- View basic product statistics on the dashboard

## Tech Used

- React
- TypeScript
- Node.js
- Express.js
- PostgreSQL
- JWT
- bcrypt

## Project Structure

- `client` - Frontend
- `server` - Backend

## Run Locally

### Backend

```bash
cd server
npm install
npm run dev

##Frontend
